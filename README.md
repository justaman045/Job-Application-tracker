# JobTracker — Smart Job Application Manager

> **Track job applications with Kanban board, offer comparison, dark mode, PWA support, and export options.**

[![Next.js](https://img.shields.io/badge/Next.js-000000?logo=next.js)](https://nextjs.org)
[![Firebase](https://img.shields.io/badge/Firebase-FFCA28?logo=firebase&logoColor=black)](https://firebase.google.com)
[![License](https://img.shields.io/badge/License-MIT-blue)](LICENSE)

## Features

- Kanban board for application stages
- Offer comparison engine
- Dark mode + PWA support
- CSV/JSON export
- Built with Next.js + Firebase

---

## Tech Stack

- Next.js + TypeScript
- Firebase
- Tailwind CSS
